## 📦 Programmatic Usage

### JSON Dataset
You can find the structured dataset in [`verbs.json`](verbs.json) and flat list in [`verbs.txt`](verbs.txt).

### JavaScript / TypeScript
```javascript
import data from './verbs.json' assert { type: 'json' };

// Get a random verb
const randomVerb = data.all[Math.floor(Math.random() * data.all.length)];
console.log(`${randomVerb}...`);

// Get all verbs in a specific category
const cookingVerbs = data.categories["Cooking & Food"].verbs;
console.log(cookingVerbs);
```

### Python
```python
import json
import random

with open("verbs.json", "r", encoding="utf-8") as f:
    data = json.load(f)

# Pick a random spinner verb
verb = random.choice(data["all"])
print(f"{verb}...")
```

### Bash / cURL
```bash
# Get a random verb from verbs.txt
shuf -n 1 verbs.txt
```
